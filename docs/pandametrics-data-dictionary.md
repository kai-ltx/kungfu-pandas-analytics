# PandaMetrics Data Dictionary

_Generated by `node tools/build_data_dictionary.js` from `apps-script/Stats.js`. Do not edit by hand._

**Confidence:** `verified` = EA named field; `high` = community-confirmed event mapping ([research](https://github.com/Interactive-63/eafc-pro-clubs-api-research), decoded by fc-clubs-api 0.3.0); `medium` = derived or caveated; `experimental` = shown with a warning, never used in scores.

**Aggregation rules:** one appearance per club + match + player; `did_not_play` rows excluded; event metrics skip rows whose events are missing or incomplete (missing is not zero); ratios pool numerator and denominator across matches; per 90 = total ÷ secondsPlayed × 5400 and only when every included row has seconds.

## Panda Score role weights

Each appearance is scored against appearances in the same position group: every weighted metric becomes a percentile (inverted for lower-is-better), then a weighted mean. Counts use per 90 with a 20-minute floor; ratios are shrunk towards the role's pooled rate by `shrinkage` attempts. An appearance needs 60% of its role's weight to be scored. Roles with fewer than 10 appearances benchmark against all appearances. A player's score is the mean of their appearance scores. EA match rating is excluded.

| Role | Metric weights |
|---|---|
| Attacker (ATT) | Goals ×3, Assists ×2, Shot accuracy ×1.5, Dribbles completed ×1, High recoveries ×1, Pass accuracy ×1 |
| Midfielder (MID) | Pass accuracy ×2, Forward passes completed ×2, Assists ×1.5, Goals ×1, Through balls ×1, Interceptions ×1, Tackles won ×1, Possession lost ×1 |
| Defender (DEF) | Interceptions ×2, Defensive-third losses ×2, Tackle success ×2, Pass accuracy ×1.5, Defensive aerials won ×1, Crosses blocked ×0.5, Out of position ×1 |
| Goalkeeper (GK) | Saves ×2, Goals conceded ×2, Pass accuracy ×1 |

## Not available from the API

- Exact position per match (only the group).
- Archetype names for `archetypeId`, PlayStyles, attribute allocations, portraits.
- Lost aerial duels (so no aerial success rate), xG/xA, distance, metres progressed, pressing.
- Goalkeeper appearances: none in samples (AI keepers).
